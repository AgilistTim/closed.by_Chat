Try Different Themes

Implementation

To add this chat widget to your website, include these two lines in your HTML:

<!-- In the <head> -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/AgilistTim/closed.by_Chat@v1.0.0/dist/chat-widget.min.css">

<!-- Before </body> -->
<script src="https://cdn.jsdelivr.net/gh/AgilistTim/closed.by_Chat@v1.0.0/dist/chat-widget.min.js"></script>

Then initialize the widget:

const chatWidget = new ChatWidget({
    position: 'bottom-right',
    theme: {
        primary: '#2196F3',
        secondary: '#ffffff',
        text: '#000000'
    },
    title: 'Chat With Us',
    greeting: 'Hello! 👋 How can I help you today?',
    placeholder: 'Type your message...',
    endpoint: 'your-webhook-url'
});
